# Eventify - Система бронирования билетов на мероприятия

## Описание проекта
Backend-система для бронирования билетов на мероприятия с разделением ролей пользователей и администраторов.
Проект разработан в рамках финальной работы курса "Разработка веб-приложений на Java".

##  Стек технологий
- **Java 21** + **Spring Boot 3.5.7**
- **PostgreSQL** - реляционная база данных
- **Spring Data JPA** + **Hibernate** - доступ к данным
- **Spring Security** - аутентификация и авторизация
- **Liquibase** - миграции базы данных
- **MapStruct** - маппинг DTO и сущностей
- **Lombok** - сокращение boilerplate кода
- **Swagger/OpenAPI 3** - документация API

##  Реализованные функции

###  Аутентификация и безопасность
- Регистрация и вход пользователей
- Хеширование паролей (BCryptPasswordEncoder)
- Spring Security с настройкой CORS
- Разделение ролей USER/ADMIN

###  Управление мероприятиями
- Создание, просмотр, обновление, удаление мероприятий (ADMIN)
- Автоматический расчет доступных билетов
- Валидация дат мероприятий

###  Бронирование билетов
- Бронирование с проверкой доступности мест
- Подтверждение/отмена бронирований
- Время жизни бронирования (24 часа)
- Возврат билетов при отмене
